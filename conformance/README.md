# AuSM Conformance

本目录用于承载 AuSM 的黄金语料、交换样例与一致性测试。当前仅公布验收契约，**尚未提供可执行的完整测试套件**。

## 声明等级

| 声明 | 通过条件 |
| --- | --- |
| Core-Structural | 交换文档通过 Core Schema 与引用完整性检查 |
| Core-Lifecycle | 通过 Core §6 的 C-01～C-15 中适用的测试，并公开不适用理由 |
| Core-Interchange | 两个不同宿主 Profile 读写同一黄金语料，保持核心语义，并分别通过以上两级验证 |
| 平台无关实现 | 至少两个不同宿主完成 Core-Interchange |

作者自己的第二适配器可以验证可移植性；第三方只凭规范实现可以进一步验证规范的可理解性。两者是不同的证据，不互相替代。

## 最低覆盖

一致性测试必须覆盖 Schema、历史追加、快照修订与失败、显式交代、证据引用、时间更新、锚点作废、交接预算、作用域隔离、索引重建、迁移往返、检索不造证、跨模型交接与扩展往返。

完整定义见 [AuSM Core Spec v0.1](../docs/spec/AuSM-Core-v0.1.md)。

## 黄金语料原则

- 使用合成或明确授权的数据，不依赖真实用户隐私。
- 同时包含普通案例、边界案例和 AuSM 可能失败的案例。
- 覆盖用户纠正、过期计划、冲突来源、self-report、作用域、预算、跨模型交接、拒答与重复导入。
- 预期结果必须可公开复核，不能只写“效果较好”。
